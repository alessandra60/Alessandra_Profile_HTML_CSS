# Alessandra Profile – HTML & CSS

A simple and clean personal profile page built using **HTML** and **CSS**, showcasing professional information, skills, and contact details.

## 🎯 Purpose

This project demonstrates:
- Semantic and well‑structured HTML
- Responsive layout using CSS
- Clean visual design and typography
- A straightforward personal profile page without JavaScript

## 🧱 Technologies Used

- **HTML5**
- **CSS3**

## 📂 Project Structure

- **`index.html`** — Main profile page (about, skills, contact)
- **`styles.css`** — Global styles, layout, colors, and responsive rules
